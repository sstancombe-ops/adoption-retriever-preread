Success Guidance Entry · Get Product Guidance

Unauth (always) · Auth ineligible fallback · Prod contract Aug 31 · Agent V2 100%

Home · Get Product Guidance → Full-screen Agent · Success Welcome → User picks 1 · 2 · or 3 → Topic + retriever below

When this door shows

  • Unauthenticated on Help Home (always-on GPG card).
  • Authenticated but not Onboarding- or Adoption-eligible and no resumable In Progress.

Hard constraints

  • Unauth never enters Adoption (needs auth + entitlement + CSS unused = 0).
  • Adoption Retriever is auth-only — unauth best practices / OOS use Knowledge.
  • Onboarding Success door = Sales / Service only (AF/DC nested).
  • Non-EN Welcome: no option 1 (setup + best practices only).

Post-selection · what happens

1Unused features (Adoption teaser)

“Sign in to learn what Sales or Service features I'm not using”

While still unauth
Trigger standard login. Do not start Adoption. Keep pre- and post-login turns in the same transcript.
After login
Run Adoption eligibility (entitlement + CSS unused-feature = 0) before any Adoption topic.
If eligible → topic
Adoption subagent Sales / Service / FINS (Sept experience). AF/DC not an Adoption topic yet.
Retriever hit
Adoption Retriever product-aware filter for the eligible cloud. Not Knowledge.
Deterministic experience
Unused-feature / Discover-style guidance for CSS = 0 avenues. Org-personalized after auth.
If not eligible after login
No Adoption topic. Explicit fallback (“I only have insights on certain [product] capabilities…”) → offer options 2 and 3 / Knowledge. Do not silent-fail into a generic Adoption script.

2Configuration help (Onboarding)

“Get help with Salesforce configuration”

Intended topic
Onboarding subagent when product is Sales or Service (or setup intent without a named OOS cloud). Prod = Agent V2 100% — option 2 hands off to Onboarding.
Retriever hit
Adoption Retriever (shared O&A index) with Onboarding topic / checklist instructions — Sales or Service parent; AF/DC only as nested Phase 4 when entitled, not a standalone Success door.
Deterministic experience
Checklist phases → steps → actions. Progress not saved until login; Agent should say so. Stay in Onboarding until exit criteria (V2 stickiness).
If OOS product named
Do not start Onboarding or Adoption. Route to Knowledge with citations. Optional login invite only if it would unlock a real Success topic.
Mid-conversation OOS
Off-topic returns to primary router → Knowledge, not a forced Sales/Service checklist step that ignores the utterance.

3Best practices (Knowledge)

“Learn best practices for configuring and using Salesforce”

Topic
Knowledge (Help Agent Knowledge ensemble). Never Onboarding or Adoption.
Retriever hit
Knowledge Retriever / Help ensemble — not the Adoption Retriever. Citations required.
Deterministic experience
Clarify product / role / goal first, then cited best-practice answer. No unused-feature / CSS personalization. No checklist progress.
Any product
Works for in-scope and OOS clouds. Do not promise “features you're not using” without login + eligibility.

Agentforce + Data Cloud

Onboarding = nested under Sales/Service · Adoption when CSS experience live

Entry / CTA

No standalone Get Started AF/DC card. Enters via Sales/Service Get started / Continue → Phase 4. Standalone “start Agentforce” free-text → clarify use case / parent cloud.

Systems + signals

AF/DC SKUs on Graph · nested in Sales/Service checklist · Adoption AF/DC CSS when unlocked · shared retriever already has AF/DC content

Agent does

Onboarding: Phase 4 AF use cases + DC enablement inside parent journey. Adoption (if live): AF/DC avenues from CSS — else do not open AF/DC Adoption topic.

OOS / limits

Unauth “onboard me to Agentforce” → Knowledge / login — not a Success AF door. Don’t promise unused AF features until Adoption AF/DC CSS-ready.
