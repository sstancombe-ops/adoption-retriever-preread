Financial Services

Adoption first · Onboarding gated / later · #3 Adoption (Industry)

Entry / CTA

Discover Capabilities · Set up my unused Financial Services features

Systems + signals

FINS entitlement · CSS foundational FINS IDs · display label “Financial Services” (not “Industry”)

Agent does

Adoption topic for FINS avenues only. Retriever filter = FINS. Do not start Sales Onboarding from a FINS Discover click.

OOS / limits

If FINS Onboarding still gated — no Get Started FINS card; Knowledge or wait for unlock.

Agentforce + Data Cloud

Onboarding = nested under Sales/Service · Adoption when CSS experience live

Entry / CTA

No standalone Get Started AF/DC card. Enters via Sales/Service Get started / Continue → Phase 4. Standalone “start Agentforce” free-text → clarify use case / parent cloud.

Systems + signals

AF/DC SKUs on Graph · nested in Sales/Service checklist · Adoption AF/DC CSS when unlocked · shared retriever already has AF/DC content

Agent does

Onboarding: Phase 4 AF use cases + DC enablement inside parent journey. Adoption (if live): AF/DC avenues from CSS — else do not open AF/DC Adoption topic.

OOS / limits

Unauth “onboard me to Agentforce” → Knowledge / login — not a Success AF door. Don’t promise unused AF features until Adoption AF/DC CSS-ready.

Marketing Cloud Next

Onboarding + Adoption · Marketing App only · after Sales/Service in multi-product sort
